# Anu Birthday Website

A photo-free animated birthday surprise website.

## Files
- `index.html` — complete website
- `romantic.mp3` — background music
- `.nojekyll` — GitHub Pages helper

## Publish on GitHub Pages
Upload all files in this folder to the root of your repository, replacing the previous version. Keep `romantic.mp3` beside `index.html`. Then enable or refresh GitHub Pages.

The former photo gallery and photo slideshow pages have been replaced with animated note chapters. No photo files are required.
